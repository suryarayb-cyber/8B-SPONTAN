07 // FAQ

Pertanyaan yang sering ditanya.

Website ini dibuat pakai apa? +

HTML, Tailwind CSS lewat CDN, JavaScript murni, dan Firebase Realtime Database.

Siapa yang membuat Website Ini? +

Hanya owner kelas. Sistem akses tersembunyi lama tetap dipertahankan: klik logo 3 kali cepat atau gunakan Ctrl + Shift + L, sesuai logic JavaScript yang sudah ada.

Bisa request fitur baru? +

Bisa. Kirim lewat halaman Kontak atau melalui pengurus kelas.

Bagaimana dengan data Firebase? +

Koneksi Firebase dari website lama tetap digunakan. Tampilan baru ini tidak mengubah konfigurasi atau script database.
